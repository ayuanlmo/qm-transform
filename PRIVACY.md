# Privacy Policy for QM-Transform

Last updated: 2026-11-15

QM-Transform is a free and open-source media format conversion tool. We respect your privacy.

## Data Collection
This application does **not** collect, store, transmit, or share any personal information or user data.

## Internet Access
Although the application requires internet access (for features such as checking for updates or downloading optional components), no data is sent to our servers.

## Source Code
The source code is publicly available on GitHub and can be audited by anyone.
